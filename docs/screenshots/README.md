# مجلد لقطات الشاشات المرجعية
## Reference Screenshots Directory (`docs/screenshots/`)

هذا المجلد مخصص لحفظ صور ولقطات الشاشات المعتمدة نهائيًا في نظام **VERTEX ERP**.

---

### إرشادات حفظ وتسمية الصور (Naming & Metadata Guidelines):

لتنظيم الأصول البصرية وتسهيل تتبعها دون تكرار أو فوضى، يُرجى اتباع القواعد التالية عند إضافة أي لقطة شاشة:

1. **صيغة اسم الملف:**
   `[ScreenName]_[ViewType]_[Status]_[YYYY-MM-DD].[ext]`
   - أمثلة:
     - `warehouses_records_modal_approved_2026-10-10.png`
     - `treasuries_master_view_trial_2026-10-10.png`
     - `customers_master_view_review_2026-10-10.png`

2. **أنواع العرض (`ViewType`):**
   - `master_view`: للبطاقة الرئيسية وشاشة الإدخال.
   - `records_modal`: لنافذة استعراض السجلات ودليل البحث.
   - `statement_modal`: لنوافذ كشوف الحسابات والحركات.
   - `table_detail`: لقطة مقربة لجدول أو تفصيل معين.

3. **الربط مع سجل المراجعة:**
   - عند إضافة أي صورة إلى هذا المجلد، يجب توثيق اسمها وتاريخ التقاطها في ملف `docs/design/SCREEN_AUDIT_LOG.md` في خانة الملاحظات المقابلة للشاشة.

> **تنبيه:** المجلد فارغ حالياً ومخصص لاستقبال اللقطات المعتمدة الفعلية فقط، ولا يحتوي على أي صور وهمية أو تجريبية.
