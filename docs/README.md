# دليل التوثيق المرجعي لتصميمات واجهات VERTEX ERP
## VERTEX ERP Design Specifications & Documentation Hub

مرحباً بك في مركز التوثيق المرجعي الشامل لتصميمات الواجهات والمواصفات البصرية لنظام **VERTEX ERP**.

---

## 1. القاعدة الإلزامية للمساعدين وأدوات البرمجة الذكية (Developer & AI Agent Instructions)

> ### ⚠️ قاعدة العمل الإلزامية قبل تعديل أي شاشة:
> 
> 1. **تحديد القائمة والوحدة التابعة لها:** عند طلب تعديل أو ضبط بصري لأي شاشة، يجب أولاً تحديد القائمة الرئيسية التابعة لها الشاشة من بين القوائم السبع.
> 2. **القراءة المسبقة:** يجب قراءة **المرجع العام** في `docs/design/VERTEX_SETTINGS_UI_DESIGN_STANDARD.md`، ثم قراءة **مرجع القائمة الفرعية المختصة** (داخل مجلدها المخصص في `docs/`) قبل البدء في كتابة أو تعديل أي كود.
> 3. **الالتزام بالنطاق المطلوب فقط (Strict Scope):** تُستخدم المواصفات المعتمدة لتوحيد الشكل البصري، مع الالتزام التام بتعديل النطاق المطلوب فقط، دون إعادة هيكلة (Refactoring) غير مطلوبة، ودون تعديل ملفات أخرى أو تغيير المنطق الوظيفي وقواعد البيانات.
> 4. **حالة الاعتماد:** إذا لم تكن الشاشة معتمدة بصريًا، **فلا تفترض أن تصميمها الحالي هو المعيار النهائي**، ولا تنسخ تصميم شاشة أخرى بالكامل دون مراجعة وتدقيق مع المستخدم.
> 5. **تحديث سجل التدقيق:** بعد أي فحص أو تعديل ناجح، يجب تحديث سجل المراجعة العام وسجل القائمة الفرعية لتوثيق الحالة الفعلية.

## 2. هيكل نظام التوثيق العام والفرعي

ينقسم نظام التوثيق إلى مستويين متكاملين:

### المستوى الأول: المراجع العامة المشتركة (`docs/design/` و `docs/screenshots/`)
- **`docs/design/VERTEX_SETTINGS_UI_DESIGN_STANDARD.md`:** الدليل المرجعي العام المشترك للألوان، خط Cairo، أحجام النصوص، أبعاد الحقول، وهوامش النوافذ المنبثقة.
- **`docs/design/SCREEN_AUDIT_LOG.md`:** السجل العام لمراجعة واعتماد جميع شاشات النظام.
- **`docs/design/components_catalog.md`:** كتالوج المكونات المشتركة الفعلية في `src/components/common/`.
- **`docs/screenshots/`:** مجلد حفظ اللقطات المرجعية المعتمدة.

### المستوى الثاني: مراجع القوائم الرئيسية السبع
تتوزع شاشات النظام بحسب الواجهة الرئيسية إلى سبع قوائم مستقلة لكل منها مواصفاتها وسجل شاشاتها:

1. **المخزون والمخازن (`docs/inventory/`):**
   - يشمل بطاقات المخازن، نوافذ السجلات، والتحويل المخزني.
2. **المشتريات (`docs/purchases/`):**
   - يشمل فواتير الشراء، إدارة المشتريات، وبطاقات الموردين المرتبطة.
3. **المبيعات (`docs/sales/`):**
   - يشمل أوضاع إدخال المبيعات، مرتجعات البيع، وبطاقات العملاء المرتبطة.
4. **الإعدادات (`docs/settings/`):**
   - يشمل إعدادات النظام، التصنيفات، شجرة الأصناف، والمستخدمين والصلاحيات.
5. **التقارير (`docs/reports/`):**
   - يشمل تقارير الحركات، الترويسات الموحدة للطباعة والتصدير، ومحرك التحليلات.
6. **الخزينة والحسابات (`docs/finance/`):**
   - يشمل بطاقة الخزائن، كشوف الحركة، شجرة الحسابات، والعمليات المالية المقبوضة والمصروفة.
7. **قائمة VERTEX ERP (التصفير والربط ومحرك النظام) (`docs/vertex-system/`):**
   - يشمل نافذة المطورين وأصحاب النظام، إعدادات محرك SQL Server، تهيئة وتصفير العمليات، والترقية.

## 3. ميثاق الحفاظ على الوظائف
كل توحيد بصري أو تعديل تصميمي يجب أن يراعي بدقة عدم المساس بـ:
- معالجات الأحداث (Event Handlers).
- مفاتيح الحقول في النماذج (State variables).
- دوال الحفظ والتحميل والاتصال بقواعد البيانات أو التخزين المحلي.
- معايير الأمان وتأكيدات الحذف والتصفير.
