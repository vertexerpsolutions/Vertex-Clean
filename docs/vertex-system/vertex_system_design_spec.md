# مرجع تصميم قائمة: VERTEX ERP (التصفير والربط ومحرك النظام)
## VERTEX System, Developer Console & Reset Module Design Specifications (`docs/vertex-system/`)

> **القائمة المقابلة في النظام:** قائمة VERTEX ERP الخاصة بالتصفير والربط ومحرك النظام  
> **المدخل في الواجهة الرئيسية:** زر العنوان الذهبي الكبير في الواجهة الرئيسية (`VERTEX ERP` / `Developer Console`)  
> **الأيقونة واللون المميز:** طرفية المطورين العنبرية (`Terminal` / `text-amber-400` / `border-amber-400/30`)  
> **تاريخ التحديث:** أكتوبر 2026

### 2. المواصفات البصرية المعتمدة والمتحقق منها في القائمة

- **الخط والاتجاه:** خط `Cairo` مع دعم نصوص برمجية وأكواد بخط أحادي `font-mono` باللغة الإنجليزية في مناطق الإعدادات الحساسة.
- **نافذة وحدة المطورين (`Developer Console`):**
  - الخلفية: رمادي داكن فاحم معتم `bg-slate-900 border border-slate-700/80 rounded-2xl shadow-2xl`.
  - الترويسة: أيقونة طرفية داخل كبسولة عنبرية متوهجة (`bg-amber-500/10 border border-amber-500/30 text-amber-400`).
  - أزرار التحكم: أزرار واضحة ذات حدود سميكة (`border-slate-700`) مع تلميحات أمنية صريحة.
- **عناصر التحذير والتصفير (Dangerous Operations):**
  - زر التصفير: أحمر وردي تحذيري (`bg-rose-500/20 text-rose-300 border-rose-500/40 hover:bg-rose-500/30`).
  - نافذة التأكيد: نافذة حوارية منبثقة ذات طبقة حماية عالية، تتطلب تأكيداً واعياً قبل إطلاق أمر التصفير.
- **حقول إعدادات الخادم وقاعدة البيانات:**
  - حقول اسم الخادم، القاعدة، المستخدم، وكلمة المرور: حقول واضحة تدعم إظهار وإخفاء كلمة المرور (`Eye` / `EyeOff`) مع مؤشر حالة الاتصال اللوني (أخضر للاتصال الناجح، أحمر للخطأ).

### 3. إرشادات الحفاظ على وظائف وسلوك القائمة
- يمنع منعاً باتاً تعديل خوارزمية الحماية في دالة `purgeOperationalData` داخل `systemResetService.ts`؛ فهي تمنع التصفير في حال وجود تحويلات مخزنية معلقة بين الفروع.
- الحفاظ على تكامل كائن `window.vertexDesktop.sqlServer` لضمان عدم كسر اتصال TDS في إصدار سطح المكتب المعبأ عبر Electron.
